# Password Security — 9th grade CS lesson

## Audience & tone
14-15 yo, mixed technical backgrounds. Direct, slightly edgy, relatable. Classroom projector → high contrast, big type, readable from the back.

## Title sequence (style: short edgy declaratives / topic phrases)
1. Your Password Probably Sucks — "And hackers already know it." (TITLE)
2. Have You Been Pwned? (HOOK — breach stats)
3. How Passwords Get Cracked (3 methods)
4. Length Beats Complexity (THE MATH)
5. Know the Difference (VOCAB: Password / Passphrase / PIN / Passkey)
6. Two Locks Are Better Than One (MFA/2FA)
7. Let a Robot Remember Them (PASSWORD MANAGERS)
8. The Rules (Actually Good Ones) (NIST)
9. Now You Try (ACTIVITY)
10. Before You Go (EXIT REFLECTION)

Story flow: shock → how it breaks → the one math truth → vocabulary → defense layer (MFA) → tool (managers) → checklist → do it → reflect. Reads cleanly from titles alone.

## Design system
- Dark cybersecurity. Deep navy bg, electric blue + bright green accents.
- BG: #070b16 (deepest), panels #0e1730 / #111c38, hairlines rgba blue.
- Electric blue accent: #2f9bff. Bright green accent: #34f5a3. Use green for "good/strong", blue for neutral highlight, red/amber #ff5d6c for "weak/danger".
- Text: #eaf1fb, muted #8493b4.
- Fonts: Space Grotesk (display headlines), IBM Plex Sans (body), JetBrains Mono (stats / crack times / terminal feel).
- Mono used for: breach numbers, crack times, code-y labels. Gives the "terminal" cyber feel without clip art.

## Layout system
- Section/title eyebrow: mono, uppercase, tracked, blue or green.
- Slide number bottom-left mono. Credit footer on title + exit.
- Header slides: big Space Grotesk title top-left, eyebrow above.
- Reusable card: panel bg, thin blue hairline border, NO rounded-left-accent trope.
- Visual variety: title (full), big-stat hook, 3-col methods, bar-compare math, 4-col vocab table, ranked MFA list, manager split, checklist, activity callout, 3-question reflection.
